# Ganapati Uttara Pūjā evidence

This directory preserves the compact evidence used to append the complete **Ganapati Visarjana Vidhana (Uttara Pūjā)** recording `oU7gUCqhiBI` to the existing Ganapati guide.

It contains:

- the untouched full-recording `gpt-transcribe` response;
- an independent 180-second pass with 15-second overlaps;
- an independent contiguous 120-second pass;
- four 30-second transcripts centered on the contiguous joins;
- the original YouTube Hindi-script auto-caption track, losslessly compressed as `.vtt.gz`;
- source metadata and checksum;
- the complete reconciled source and Roman layers plus block-level provenance.

The downloaded source and temporary WebM chunks are intentionally omitted because they can be reproduced from the source URL. The five compressed practice clips used by the published guide are stored under `site/audio13/`.

No API key or authorization header is stored in these files.
