# Śrī Anantapadmanābha Vrata guide evidence

This directory preserves the compact evidence used to build the complete Roman-script guide from YouTube recording `-hLoAfCk2Mg` (**Sri Ananthapadmanabha Vratha-Madwa**, 56:40).

It contains:

- the untouched `gpt-transcribe` responses from a 300-second contiguous native-script pass;
- an independent 300-second pass prompted for Roman transliteration;
- an independent 600-second pass with 30-second overlaps;
- eleven 30-second transcripts centered on every contiguous join;
- source metadata and stream metadata;
- the complete reconciled source and Roman layers;
- the exact block-level provenance and the structured-output responses used for language separation and translation.

YouTube reported no manual or automatic caption tracks for this recording. The independent GPT passes and boundary excerpts therefore serve as the additional coverage witnesses.

The downloaded source and temporary WebM chunks are intentionally omitted because they can be reproduced from the source URL. The source WebM used for this build had SHA-256 `44c586d64607d812151188ae6ab25a336b360f6159cae94d52088281b59966d4`. The twelve compressed practice clips are stored under `site/audio14/`.

The published guide reconstructs all 31,318 characters of the selected native-script backbone exactly across 154 ordered blocks. No API key or authorization header is stored in these files.
